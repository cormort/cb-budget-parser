# 中央銀行預算書 PDF 解析工具

純前端單檔工具，把中央銀行年度預算書 PDF 裡「有科目編號的預算表」抽成可篩選、可匯出 xlsx 的表格。

線上使用：<https://cormort.github.io/cb-budget-parser/>

本工具只為中央銀行預算書而寫，不做通用推論：章節、表次與各表欄位都依央行預算書格式寫死。

## 能解析什麼

### 預算表（有科目編號的表）

損益預計表、盈虧撥補預計表、現金流量預計表、金融保險收入／成本明細表、營業外收入／費用明細表、業務費用明細表、管理費用明細表、固定資產建設改良擴充（含資金來源、預期進度）明細表、資產折舊／報廢／變賣明細表、資金轉投資及其盈虧明細表、資本增減與股額明細表、資產負債預計表、員工人數／用人費用／各項費用彙計表、5 年來主要營運項目量值明細表等。

### 編列說明（科目｜說明 兩欄式）

金融保險成本說明、業務費用說明、管理費用說明、營業外費用說明——逐科目寫明編列依據，
例如「津貼：係房租津貼（未配住宿舍主管房屋津貼每人每月 5,000 元）」。

說明頁只有科目名稱沒有編號，工具會用**科目階層路徑**回查對應的明細表，把編號與本年度
預算數接上去（116 年度附件二 89 列有說明的科目中對到 86 列）。對不到就留白，不會猜。

只有附件二有逐科目的說明；附件一（合併版）僅有損益預計表說明。

所有表格的欄位都已依央行格式寫死。表頭在 PDF 裡會被拆成一個字一格、或把好幾欄畫在同一格用空白隔開，解析時會先依字距與字數還原成詞再定位。

## 實測

110–116 年度共 14 份 PDF（附件一合併版與附件二）一次丟進去：173 張表、6,703 列，
編列說明 42 頁 869 列。**表內驗算 11,769 項、同檔表間勾稽 258 項，0 項不符**；另有 970 項
因子科目數字從缺而無法驗，如實計入「無法驗」而不是當成 0。173 張表中 170 張（98.3%）
套用固定欄位規格，其餘 3 張因該年度版面不同而退回推論。

加入跨頁對開合併後，受影響的表差距很大，例如金融保險收入明細表從 3 個數字欄變成 11 個
（原本整個「外幣部分」與「合計」都沒抓到）。

## 資料來源

行政院主計總處「中央政府總預算附屬單位預算」→ 中央銀行。下載的是 zip，請先解壓出裡面的 PDF 再上傳。

## 技術重點

### 一、亂碼還原

這份 PDF 的內嵌字型沒有 ToUnicode 對照表，直接複製文字或用一般工具抽取都是亂碼
（`中央銀行` 會變成 `ύѧሌՉ`）。pdf.js 取回的碼位其實是**可逆位移**後的結果，分兩種：

| 字型 | 用途 | 還原方式 |
|---|---|---|
| 明體 | 內文、表格 | 碼位加固定位移即落回 CJK／全形符號／中文標點／ASCII 四區 |
| 楷體 | 標題 | 碼位減 436 即 Big5 字序，組回 Big5 兩位元組交給 `TextDecoder('big5')` |

兩種字型無法從 `textContent` 分辨（`fontFamily` 只給 `serif`/`sans-serif`），
所以兩邊都解、取落在合法字區較多的那個——實測 4,395 個 text item 只有 9 個
單字元標點判錯，且都在敘述段落，表格數字不受影響。

**逐字型判斷，不能逐 item 判斷**：有些單字的亂碼剛好落在正常中文區
（「說」會變成「婒」），逐 item 看就會被當成正常字放過。同一字型只要有任何一個
item 帶亂碼字，整個字型就一起解。

**有些年度本來就有 ToUnicode**（110–114 實測），取回的字是對的，套解碼反而會弄壞
（「營業收入」會變成「營駅閎膽」）。這種只做 NFC 正規化——那些檔案用的是 CJK
相容表意文字（U+F900 區），外觀相同但碼位不同，不正規化連字串比對都會失效。

**需要 pdf.js 4.x**：2.10 對這幾個字型會額外做字形代換（數字會變成 `IJ`、
`折` 會變成 `(祭)`），4.x 取回的碼位才是乾淨的等距位移。

### 二、版面解析

以含「編號」的表頭列把頁面切開：其上是表名與欄位標題，其下是資料列。

- **科目名稱**：層級首字常另成一格、或同位置重疊繪製，相鄰格互為前後綴時去重；只有文字沒有編號與數字的列併回上一列。
- **無編號的列**：表尾的「合計」「總計」與最上層科目沒有編號，照樣收。註腳與被擠進表格的說明文字也沒有編號，用「名稱超過 12 字」砍掉。**註腳不併進上一列**：頁尾的「註：…」若被當成續行黏上去，科目名稱會變長又帶到全形冒號而被砍掉，整列跟著消失（實測有 45 個合計／總計列是這樣掉的）。
- **被併掉的相鄰格**：pdf.js 偶爾把相鄰兩格併成一個 text item（`389,793,351 100.00`、`410301 312,864,414`）。不拆的話前者讓整列的金額與％消失，後者更會讓科目名稱變成「利息收入410301412,149,742」而整列被砍掉。拆法是依字數比例還原 x，但**不能看到空白就拆**——「1 0 0 , 3 1 8」是同一格拉開字距，拆了會多出七格假數字。
- **編號欄的右緣**：科目編號靠左對齊、金額靠右對齊，9 位數金額的左緣只離「編號」表頭右緣 2.7pt。用表頭右緣 +6pt 當編號欄範圍會把整格金額吃掉（實測損益預計表、現金流量預計表共 130 格），所以改取本頁**實際編號格**的最大右緣，並且用右緣判斷是不是落在編號欄裡。範圍編號（`974510102-6`）也要認，不然它會漏進科目名稱把整列擠掉。
- **單雙頁位移**：裝訂邊讓同一張表的單頁與雙頁整頁差 12pt，不校正的話每一欄都會被拆成兩欄。以「編號」欄的 x 為基準把各頁對齊到第一頁。
- **欄位**：整張表（含所有頁與對開右半）一起算，分頁各算各的會讓「某頁剛好沒資料」的欄整個消失。先以固定規格的表頭字樣在表頭上定位各欄，再把資料欄「保序」配上去（不是各自取最近的——欄距只有 50pt 左右，取最近很容易整排錯開一格）——整欄沒資料時（金融保險成本沒有「固定」）其他欄才不會錯位；定位不到就退回欄數比對，再不行才依表頭推論並標示。欄位一個都不能少：多出來的只允許丟「值極少」的雜訊群（說明欄裡的數字、被誤認的編號）。規格欄都定位到時，離每一欄都超過 40pt 的資料欄一定是雜訊（被擠進表格的註腳小表），先剔除再配——留著會讓整張表的欄名一起退回推論。
- **驗算**：見下方「驗算」一節。
- **左右對開的大表**：印成兩頁，右頁沒有「編號」欄。偵測方式是比對兩頁資料列的 y 座標——實測 42 組相鄰頁，真的是對開的命中率 ≥57%，不是的 ≤11%，門檻取 40%；右頁若自己就有完整的已知表名（那是另一張表）則排除。合併時把右頁的 x 加一個大於頁寬的位移，兩頁就落在同一個座標系。
- **表名**：在 PDF 裡常被拆行且字序錯亂（`現金流量預計表` 會變成 `表量預計流金現`），用字元重疊度比對已知表名還原；跨頁表會併入下一頁頁首再比對。
- **階層**：由科目名稱的左緣縮排推算。

## 呈現方式

**每一張表是一個頁籤**，依央行預算書的章節與表次由左至右排列，章節名夾在頁籤流裡當分隔：
丙、預算主要表 → 丁、預算明細表（壹、損益明細科目／貳、現金流量明細科目）→ 戊、預算參考表
→ 己、附錄 → 編列說明。點頁籤切換，同時只顯示一張表。

最前面另有一個**「表間勾稽」頁籤**，把跨表的每一筆關係逐條列出來：「哪一張表的哪一個科目・
欄位」應該等於「哪一張表的哪一個科目・欄位」，連兩邊的金額、差額與結果。這一頁預設不打開
（開檔先看損益預計表），要對帳時再點。

- **欄數依畫面寬度換算**：每欄至少 200px，填滿一列再換下一列（1450px 寬約 6 欄，
  一個年度的 18 張表加編列說明排成 5 列）。視窗縮小會自動變成更多列。
- 頁籤分兩行：上面是表名，下面是頁次。頁次壓成區間（`65、66、67、68、69、70` → `65-70 頁`），
  否則像資產負債預計表這種跨 6 頁的表，表名會被頁次擠到只剩「資…」。
- 只有一份 PDF 時頁籤上不放檔名（一次只看一個年度）；若同時載入多份，檔名會加在頁次前面。
- 表名太長會截短，完整表名、頁次、列數與驗算結果在表格上方那一列；滑過頁籤也會顯示完整標題。
- 驗算有問題的頁籤會帶一個 ⚠ 記號。
- 篩選框輸入科目名稱或編號時，會同時過濾所有頁籤裡的列；目前這張表若沒有命中，會自動跳到
  第一張有命中的表，沒有命中的頁籤變淡。

匯出的 xlsx 照同一個順序，最後附「表內驗算（不符）」、「驗算彙總」與「表間勾稽」三張工作表
——後兩張不管過不過都把每一條列出來，驗了哪些本身也可查。

甲、財務摘要與乙、業務計畫及預算概要是敘述與圖表，沒有科目編號欄，不解析。

## 驗算

表內驗算分三種關係，畫面上分開顯示，不符時才知道是哪一種壞掉：

| 類型 | 關係 | 涵蓋 |
|---|---|---|
| 散總 | 母子科目加總（科目編號的前綴階層，510301 → 5103014 → 51030146） | 丙、丁、戊（5年來主要營運項目量值明細表除外，見下） |
| 表尾合計 | 表尾「合計」「總計」列 = 最上層科目之和 | 有單一合計列的表 |
| 恆等式 | 財報科目之間固定的加減與乘除 | 逐表列出，見下 |

**對沖科目**以減項處理，不然相加本來就不等於母科目：`備抵`／`累計`開頭的一律是減項；
資產科目（1x）底下的「應付…」與負債科目（2x）底下的「應收…」也是——應收／應付遠匯款
（110531／110532、210527／210526）、代管資產／應付代管資產（199725／199727）都是這樣
對沖掉的。

恆等式只列實測 110–116 年度 14 份 PDF **全部成立**的關係，沒驗證過的不寫進來：

- 損益預計表：61 營業毛利 = 41 − 51；62 營業利益 = 61 − 52；63 營業外利益 = 49 − 59；
  64 稅前淨利 = 62 + 63；比較增減金額 = 本年度 − 上年度
- 盈虧撥補預計表：81 盈餘之部 = 82 分配之部
- 現金流量預計表：9003 = 9001；9005 = 9003 + 9004；9007 = 9005 + 9006；
  91 = 9007 + 9008 + 9010 + 9012；93 = Σ92xx；95 = Σ94xx；97 = 91 + 93 + 95 + 96；99 = 98 + 97
  （這張表的分項在合計之前，前綴散總驗不到，得逐條寫）
- 資產負債預計表：資產 = 負債 + 權益；比較增減數 = 本年度 − 上年度
- 費用明細表（金融保險成本／業務／管理／營業外費用）：本年度合計 = 固定 + 變動
- 固定資產建設改良擴充明細表：小計 = Σ 各資產欄；合計 = 小計 + 投資性不動產
- 固定資產建設改良擴充資金來源明細表：合計金額 = 自有資金小計 + 外借資金小計
- 用人費用彙計表：合計 = Σ 各費用欄
- 金融保險收入明細表：合計營運值 = 新臺幣部分營運值 + 外幣部分折合新臺幣
- 增購及汰舊換新管理用公務車輛明細表：合計 = 增購部分 + 汰舊換新部分
- 資產變賣明細表：帳面價值淨額 = 成本 − 已提折舊 − 減損調整數；
  變賣收入淨收入 = 總收入 − 處理費用；變賣盈餘或虧損 = 淨收入 − 帳面價值淨額
- 資產報廢明細表：帳面價值淨額 = 成本 − 已提折舊 − 減損調整數
- 5年來主要營運項目量值明細表：營運值 = 營運量 × 平均利(費)率％（比率型，容差按印到
  小數點後兩位算）
- 資金轉投資及其盈虧明細表：持股比率占發行股數％ = 年終預計持有股數 ÷ 發行股數

**跨年度勾稽**（同時上傳相鄰兩個年度、同一附件才有；年度讀表頭「中華民國○○○年度」，
附件別看事業投資利益的編號 4106／4107，不靠檔名）：N 年度書的「上年度預算數」= N−1 年度書的
「本年度預算數」。比損益預計表全部科目，以及金融保險成本／業務費用／管理費用／營業外費用明細表、
資金轉投資及其盈虧明細表的第一層科目與總計（子科目跨年會重編，差異會反映在上層）。
14 份實測 823 項，775 項相符、48 項「版本不同」、0 項不符。

「上年度預算數」是哪個版本，損益預計表底下有註：111–114 年度書是「法定預算數」，115、116 年度書
是「預算案數」。今年書的上年度欄是預算案、手上的去年檔卻是立法院審定版（或反過來）時，差額是立法院
審議造成的，標「版本不同」，差額照列但不算不符。115 年度書對 114 審定書的 48 項就是這樣：審定數比
預算案增列事業投資利益 4,000 千元、刪減費用 196,000 千元，本期淨利剛好多 200,000 千元。去年檔的
版本只有檔名看得出來（「立法院審定數」／「行政院核定數」），檔名沒寫就照常比。
資產負債預計表的「上年度預計數」是重新估計的數字，跟前一年書對不上（實測 1,284 項），不比。

畫面上每一條都寫出兩邊各自的「表名＋科目編號＋科目名稱＋欄位」。

後半幾條（信託投資利益、匯率影響數、流動金融負債、存入保證金、現金淨增減）是把同一份文件裡
所有跨表的相同金額掃過一遍，只留 14 份都成立、且會計上說得通的關係。掃到但沒採用的：
「5年來主要營運項目量值明細表」的營運量（年度對位不穩，14 份只有 10 份對得上）。

### 附表有提到、但做不到的勾稽

「附錄參–二」是**作業基金**（大學校務基金、地方總決算）的書表格式，科目與央行不同，其中有
四條對不到央行的表：貸出款明細表對平衡表長期貸款、長期債務明細表對平衡表長期負債、
所屬作業單位收支概況表對收支餘絀決算表、總說明計畫項目對主要營運計畫執行績效摘要表
（央行預算書沒有這幾張表）。

還有一條是**工具的限制**而不是資料的問題：附錄附表 B8 要求「本年度提列折舊數應與各項費用
彙計表所列折舊費用相符」，但央行的「資產折舊明細表」「各項費用彙計表」「會費、捐助與分攤
費用彙計表」「媒體政策及業務宣導費彙計表」「一般建築及設備計畫之分年性項目明細表」這五張表
是「項目／費用別／項目及對象／金額」的**無編號表格**（14 份 PDF 每份都有），工具目前只解析
有「編號」欄的預算表，所以這五張表一張都沒進來，折舊那條勾稽因此無法做。

容許四捨五入尾差：每個子項 0.5 元，比率型另按印出的位數算。**數字從缺一律列為「無法驗」**，
不猜它是 0——那可能是漏抓，也可能是本來就沒有。

附件一與附件二是同一份預算的兩種版本，科目編號與範圍不同（附件一含造幣、印製廠），彼此不勾稽。

## 驗證

驗算規則不是憑空寫的，是對 14 份 PDF 量測後只留下成立的那些；改動解析或驗算後應該重跑：

```
npm i                                   # 只裝 tools/ 用的 pdfjs-dist
node tools/harness.mjs _a*.pdf          # 跑同一份解析邏輯，列出驗算不符的項目
node tools/harness.mjs --html out.html _a*.pdf   # 另存畫面成靜態頁
node tools/falsify.mjs                  # 否證：故意改壞數字，確認驗算真的會叫
node tools/dump.mjs <pdf> scan          # 掃出每一頁被認成哪張表
node tools/dump.mjs <pdf> raw39         # 印出第 39 頁的原始文字格（座標除錯用）
```

`tools/harness.mjs` 把 `index.html` 的模組腳本抽出來，在 Node 裡補上瀏覽器全域後執行同一份
程式碼，所以驗的是真正出貨的邏輯，不是另一份複製品。`--json out.json` 可另存完整結果，
`--html out.html` 可把畫面存成靜態頁檢查。

## 已知限制

- 金額取自原文，但科目名稱、欄位名稱與階層都是座標推算的結果，引用前請回對原始 PDF。
- 少數年度的部分表（如某些年度的盈虧撥補預計表、金融保險收入明細表）表頭寫法不同，目前抓不到。
- 110–112 年度的資金轉投資及其盈虧明細表表頭被拆得太碎（「總額」散成「總」「額總」「額」三格），欄名退回依表頭推論（畫面標示「欄名推論」）。資料位置仍正確，只是欄名偏冗長。
- 編列說明裡若夾了小表格（金融保險成本說明會列出各項存款的營運量×平均利率），會被攤平成純文字，內容不漏但失去表格形狀。
- 說明接金額是靠科目階層路徑比對，屬推論；金額請以明細表為準。
- 找不到「編號」欄的頁面（純文字的編列說明、圖表頁）不會出現在結果中。
- 「5年來主要營運項目量值明細表」的科目編號不呈前綴階層（9310 放款的子項編到 931010、931110、931140），不做散總驗算，改由「營運值 = 營運量 × 平均利(費)率％」驗。
- 表尾「合計」「總計」列在少數年度會被解碼成「葠計」（實測 6 處，都出現在資產負債預計表的資產合計列），不影響驗算，但匯出檔看起來會怪。
- 「員工人數彙計表」這幾年都沒有印「本年度增減數」欄，因此只驗到「本年度 = 上年度 + 增減」以外的部分。
- 附件一與附件二彼此不勾稽；跨檔案只做相鄰年度、同一附件的「上年度預算數」比對。
