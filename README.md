# 中央銀行預算書 PDF 解析工具

純前端單檔工具，把中央銀行年度預算書 PDF 裡「有科目編號的預算表」抽成可篩選、可匯出 xlsx 的表格。

線上使用：<https://cormort.github.io/cb-budget-parser/>

## 能解析什麼

### 預算表（有科目編號的表）

損益預計表、盈虧撥補預計表、現金流量預計表、金融保險收入／成本明細表、營業外收入／費用明細表、業務費用明細表、管理費用明細表、固定資產建設改良擴充（含資金來源、預期進度）明細表、資產折舊／報廢明細表、資金轉投資及其盈虧明細表、資本增減與股額明細表、資產負債預計表、員工人數／用人費用／各項費用彙計表、5 年來主要營運項目量值明細表等。

### 編列說明（科目｜說明 兩欄式）

金融保險成本說明、業務費用說明、管理費用說明、營業外費用說明——逐科目寫明編列依據，
例如「津貼：係房租津貼（未配住宿舍主管房屋津貼每人每月 5,000 元）」。

說明頁只有科目名稱沒有編號，工具會用**科目階層路徑**回查對應的明細表，把編號與本年度
預算數接上去（116 年度附件二 89 列有說明的科目中對到 86 列）。對不到就留白，不會猜。

只有附件二有逐科目的說明；附件一（合併版）僅有損益預計表說明。

## 實測

110–116 年度共 14 份 PDF（附件一合併版與附件二），解析出 6,491 列、1,534 個資料欄、
24,456 個有值儲存格，以「科目名稱含亂碼字／夾雜數字／空白」自動稽核，可疑 8 列（0.12%）。
116 年度附件二：預算表 28 頁 491 列、編列說明 6 頁 130 列。

加入對開合併後，欄數 1,399 → 1,534、有值格 23,775 → 24,456；單看受影響的表差距很大，
例如金融保險收入明細表從 3 個數字欄變成 11 個（原本整個「外幣部分」與「合計」都沒抓到）。

## 資料來源

行政院主計總處「中央政府總預算附屬單位預算」→ 中央銀行。下載的是 zip，請先解壓出裡面的 PDF 再上傳。

## 技術重點

### 一、亂碼還原

這份 PDF 的內嵌字型沒有 ToUnicode 對照表，直接複製文字或用一般工具抽取都是亂碼
（`中央銀行` 會變成 `ύѧሌՉ`）。pdf.js 取回的碼位其實是**可逆位移**後的結果，分兩種：

| 字型 | 用途 | 還原方式 |
|---|---|---|
| 明體 | 內文、表格 | 碼位加固定位移即落回 CJK／全形符號／中文標點／ASCII 四區 |
| 楷體 | 標題 | 碼位減 436 即 Big5 字序，組回 Big5 兩位元組交給 `TextDecoder('big5')` |

兩種字型無法從 `textContent` 分辨（`fontFamily` 只給 `serif`/`sans-serif`），
所以兩邊都解、取落在合法字區較多的那個——實測 4,395 個 text item 只有 9 個
單字元標點判錯，且都在敘述段落，表格數字不受影響。

**逐字型判斷，不能逐 item 判斷**：有些單字的亂碼剛好落在正常中文區
（「說」會變成「婒」），逐 item 看就會被當成正常字放過。同一字型只要有任何一個
item 帶亂碼字，整個字型就一起解。

**有些年度本來就有 ToUnicode**（110–114 實測），取回的字是對的，套解碼反而會弄壞
（「營業收入」會變成「營駅閎膽」）。這種只做 NFC 正規化——那些檔案用的是 CJK
相容表意文字（U+F900 區），外觀相同但碼位不同，不正規化連字串比對都會失效。

**需要 pdf.js 4.x**：2.10 對這幾個字型會額外做字形代換（數字會變成 `IJ`、
`折` 會變成 `(祭)`），4.x 取回的碼位才是乾淨的等距位移。

### 二、版面解析

以含「編號」的表頭列把頁面切開：其上是表名與欄位標題，其下是資料列。

- **科目名稱**：層級首字常另成一格、或同位置重疊繪製，相鄰格互為前後綴時去重；只有文字沒有編號與數字的列併回上一列。
- **數字欄位**：靠右對齊，所以用右緣分群成欄；欄名逐「表頭列」取中心最近的那一格再由上而下串接（群組標題是置中的，寬度常比它涵蓋的欄還窄，用區間包含會漏）。同名欄會加序號，否則會互相覆蓋掉資料。
- **左右對開的大表**：印成兩頁，右頁沒有「編號」欄。偵測方式是比對兩頁資料列的 y 座標——實測 42 組相鄰頁，真的是對開的命中率 ≥57%，不是的 ≤11%，門檻取 40%；右頁若自己就有完整的已知表名（那是另一張表）則排除。合併時把右頁的 x 加一個大於頁寬的位移，兩頁就落在同一個座標系。
- **表名**：在 PDF 裡常被拆行且字序錯亂（`現金流量預計表` 會變成 `表量預計流金現`），用字元重疊度比對已知表名還原；跨頁表會併入下一頁頁首再比對。
- **階層**：由科目名稱的左緣縮排推算。

## 已知限制

- 金額取自原文，但科目名稱、欄位名稱與階層都是座標推算的結果，引用前請回對原始 PDF。
- 少數年度的部分表（如某些年度的盈虧撥補預計表、金融保險收入明細表）表頭寫法不同，目前抓不到。
- 編列說明裡若夾了小表格（金融保險成本說明會列出各項存款的營運量×平均利率），會被攤平成純文字，內容不漏但失去表格形狀。
- 說明接金額是靠科目階層路徑比對，屬推論；金額請以明細表為準。
- 找不到「編號」欄的頁面（純文字的編列說明、圖表頁）不會出現在結果中。
